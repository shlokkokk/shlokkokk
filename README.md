I’m Shlok Shah, an IT student who loves cybersecurity, networking, and building practical tools that solve real problems.

I focus on understanding how systems behave, how attackers think, and how to build defenses through automation, scanning, and hands-on experimentation. My work revolves around security tools, network analysis, and creating utilities that help understand real attack surfaces.

### 🔥 What I do
* Build cross-platform security tools (Python & Web)
* Create scanners, analyzers, and small automation utilities
* Explore cybersecurity fundamentals through my own lab setups
* Work with Linux environments and networking concepts
* Document everything I learn through projects and notes

### 🧠 Current Focus
* Writing better, faster, and more reliable tools
* Strengthening core fundamentals (programming, networking, OS)
* Learning real cybersecurity through experiments, not theory
* Improving security logic, architecture, and documentation

### ⚡ My Approach
I like building things from scratch, testing them in isolated labs, breaking them, fixing them, and understanding the *why* behind every behavior.

If a tool teaches me something real, I build it.
